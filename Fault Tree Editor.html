How it calculates

Probabilities are per mission, as stored in the file. Each basic event is counted once however many gates it appears under: the top event and every gate are computed exactly from a binary decision diagram.

Grouping inputs under a new gate of the same type (OR inside OR, AND inside AND) adds a label without changing the result. Changing a gate's type or moving events between gates does change the logic.
