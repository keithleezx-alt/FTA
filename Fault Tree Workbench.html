Internal block diagram

Top event

The top event is the TOP EVENT node on the diagram. It isn't a component: connect the blocks whose loss causes it, using a redundancy group for k-of-n logic.

Blocks with a constant failure rate λ use P = 1 − e−λT over the mission time. Fixed-probability blocks ignore it.

Failure logic

A block's output is lost if the block itself fails, or any required input is lost, or a redundancy group is lost. A group is lost when at least k of its n inputs are lost (k = n by default). A block with probability 0 never fails on its own.

A block that feeds several others is one basic event, however many branches of the tree it appears in. Blocks given the same shared failure event tag are one physical failure drawn in several places, and also share one event. Each event is counted once: probabilities are computed exactly from a binary decision diagram, so a repeated event is never double counted.

A frame groups the failures that leave it under one labelled event in the tree, such as "Failure of primary GNSS". Frames add context only; they never change the probability.

Common-cause groups use the alpha-factor model: Qk = k / C(m−1, k−1) · αk / αt · Qt, with αt = Σ k·αk.
